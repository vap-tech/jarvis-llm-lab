# Архив LLM-сервера Arch

Это воспроизводимый снимок самописного LLM-стенда с сервера `192.168.1.204`, дополненный исходным репозиторием с ноутбука разработчика. Включены собственный код, исходники и production-сборка веб-интерфейса, конфигурации и сценарии установки. Модели, Hugging Face cache, индексируемые проекты, Python virtualenv, собранные бинарники `llama.cpp` и RAG-индексы намеренно исключены.

## Состав

- `rag-api/` — полный исходный код индексатора и HTTP API.
- `frontend/` — исходный React/Vite-проект с lock-файлом.
- `web-ui/` — развёрнутая production-сборка интерфейса, снятая с сервера.
- `system/usr-local-bin/` — запуск модели, HTTP-менеджер и старый CLI-переключатель.
- `system/etc/llama-server/` — семь профилей моделей и активный профиль на момент снимка.
- `system/etc/archsrv-rag/projects.json` — исторический реестр проектов без самих проектов и индексов.
- `system/etc/nginx/` и `system/systemd/` — точные серверные конфигурации.
- `deploy/` — чистая конфигурация проектов и автоматическая установка на Arch Linux.
- `legacy-deploy/` — первоначальные скрипты выкладки с ноутбука; они сохранены для истории и содержат старые сетевые значения.
- `docs/original/` — первоначальная спецификация RAG, заметки, TODO и тестовый prompt.
- `ARCHITECTURE.md` — устройство, API, пути, версии и известные ограничения.

## Восстановление

На чистом Arch Linux создайте пользователя `kot`, скопируйте этот каталог и выполните:

```bash
sudo ./deploy/install-arch.sh
```

Для другого пользователя:

```bash
sudo SERVICE_USER=myuser SERVICE_GROUP=myuser ./deploy/install-arch.sh
```

Установщик ставит системные зависимости, получает `llama.cpp` на зафиксированном commit, собирает Vulkan backend, создаёт virtualenv, размещает архивные компоненты и включает четыре службы. При первом старте `llama.cpp` скачает активную модель из Hugging Face; это несколько гигабайт.

Проверка после запуска:

```bash
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8081/state
curl http://127.0.0.1:8082/health
curl http://127.0.0.1/
```

Для добавления проекта используйте веб-интерфейс либо внесите путь в `/etc/archsrv-rag/projects.json`, затем вызовите `POST /rag/index` с телом `{"project":"project-id"}`.

## Разработка frontend

```bash
cd frontend
npm ci
npm run dev
```

Production-сборка создаётся командой `npm run build`. Заархивированный `frontend/dist` побайтно совпадает с файлами, снятыми с `/var/www/archsrv`.
